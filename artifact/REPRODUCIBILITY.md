# Reproducibility Notes

This artifact is configured for deterministic logical experiments. Timing can still vary with hardware and cache state, but the dataset, access plans, and result provenance are fixed.

## Fixed Inputs

- Main source dataset: `data/clickbench_32p.parquet` when running the full artifact.
- Source checksum: `data/clickbench_32p.parquet.sha256`
- Auxiliary source datasets: `data/tpch_sf1_lineitem.parquet`, generated by DuckDB with `scripts/get_data.py tpch --sf 1`; and `data/tpcds_sf1_store_sales.parquet`, generated by DuckDB with `scripts/get_data.py tpcds --sf 1 --table store_sales`
- T1 shuffle seed: `31`
- Fig.2/fullgrid shuffle seed: `17`
- Point-lookup seed: `23`
- Synthetic dataset presets: fixed in `colbench/datagen.py`
- Storage random-read gate offsets: fixed in `colbench/storage.py` with `random.Random(0xC01B_EC7)`

## Seed Recording

Every measured JSONL record stores the logical access seed at:

```json
access.seed
```

For the completed T1 run, the shuffle rows use `access.seed = 31`. Scan rows also carry the default seed field, but no random index plan is used for scans.

The analytical sensitivity report rebuilds the shuffle plan for seeds 0--63
and compares row-group touch counts without rerunning timed I/O:

```bash
python scripts/seed_sensitivity.py
```

New runs retain every repetition under the top-level `samples` field in each
JSONL record. The summary medians and IQR remain for compatibility. The
historical Alibaba Cloud and first AutoDL records predate this schema addition;
the clean AutoDL rerun retains all seven samples per cell.

After a new segmented run, compute fixed-seed bootstrap intervals with:

```bash
python scripts/bootstrap_chunk_uncertainty.py \
  'results/<run>/fig4_clickbench_32p_c*.jsonl' \
  --out results/<run>/bootstrap_chunk_uncertainty.json
```

## Expected Source Check

From `artifact/`:

```bash
sha256sum -c data/clickbench_32p.parquet.sha256
```

Distributions that omit the 2.95 GB source ship only
`data/clickbench_32p.parquet.sha256`. Rebuild the source as described above and
confirm it against that checksum before running this check, rerunning T1, or
regenerating ClickBench read-amplification outputs.

## Package Check

From the package root:

```bash
sha256sum -c SHA256SUMS.txt
```

`SHA256SUMS.txt` uses relative paths, so the check works after unpacking the
artifact outside `/root`.

## Formal P2 Reproduction Command

From `artifact/`, after installing requirements and running the storage gate:

```bash
export COLBENCH_PRUNE_COMPLETED_LAYOUTS=1
export COLBENCH_REQUIRE_RAW_SAMPLES=1
export COLBENCH_WORK=/qualified/block-device/colbench-work
export COLBENCH_DATA=/path/to/colbench-data
export COLBENCH_RESULTS="$PWD/results/p2_replication"
bash scripts/run_p2_segmented.sh
```

The selected main run requires a qualified storage gate. The original run intentionally used single-thread execution and fixed native thread environment variables inside the runner/script path. The `COLBENCH_ALLOW_UNQUALIFIED_STORAGE` override is reserved for explicitly labeled auxiliary runs such as the Alibaba Cloud mechanism check; it must not be used for a main replication.

## Independent NVMe Replication

`results/p2_qualified_20260821/` is the formal run and the source of the main
cross-format tables and three packaged plots. Reader-policy controls and
auxiliary mechanism checks use the separately labeled result sets below and
in `results/README.md`. The formal run holds eighteen checkpoints and 504 cells across three
datasets, three formats and five access patterns, measured on XFS over a
three-device NVMe RAID5 array with 540.6 GB of memory. Three storage gates
passed at 1,834--2,018 MB/s with 0.089--0.093 ms median cold random reads, and
1,674 watcher samples recorded `idle`, `mismatch_cnt=0`, and `degraded=0`. Each
cell retains seven raw samples, and each records the layout its writer actually
emitted alongside the value requested.

The reader-lifetime comparison in the paper comes from same-host probes stored
with the formal run: `probe_metadata_direct_c1024.log`,
`probe_metadata_direct_c8192.log`, and `probe_metadata_footer.log` in
`results/p2_qualified_20260821/`. `results/autodl_nvme_clean_20260816/` is an
earlier run under the per-batch reader protocol on a different host. It is kept
for audit history and must not be pooled with the formal run.

`results/autodl_nvme/` preserves the earlier AutoDL run for audit history. Its
MD mismatch counter was 384, so it is not selected by the comparison script or
used as the qualified replication.

Regenerate the main-run chunk figure from the formal results:

```bash
python scripts/report.py \
  'results/p2_qualified_20260821/p2_clickbench_32p_c*.jsonl' \
  --cache-mode cold --threads 1 --dataset clickbench_32p \
  --only-chunk --out figures
```

The paper figure covers all six predeclared settings. The default noise guard
omits one Parquet projection cell at 524,288 rows; the paper discloses that
omission, and the cell determines neither a reported optimum nor a span.

Some analysis scripts still default to top-level legacy files from the auxiliary
host and the discarded protocol. The paper-figure entry points require explicit
qualified inputs; `results/README.md` lists the remaining affected paths.

## Regenerating Read-Amplification Outputs

`scripts/read_amplification_report.py` reads Parquet footer metadata from each
chunk layout. If the materialized layouts have been pruned, the script
regenerates the six Parquet layouts from `data/clickbench_32p.parquet` and
removes them after use. Budget roughly 6 GB of temporary working space.

Generate the derived values and render the paper's read-amplification figure
with explicit qualified inputs:

```bash
python scripts/read_amplification_report.py \
  --dataset clickbench_32p \
  --out-csv results/p2_qualified_20260821/read_amplification_p2.csv \

```

## Reader Policy and Evidence Scope

One timed repetition executes the complete access plan with one reader per
access. Cache preparation happens before timing; reader initialization is
part of the access cost. Reopening a reader for each of the 64 shuffle batches
is the discarded protocol, not an alternative implementation of the same
measurement. The RAID1 control and RAID5 formal sweep also differ in hardware,
so their 77.93x and 8.58x spans alone do not isolate the reader-policy effect.
The same-host direct probes isolate that effect: 236.963 versus 15.053 seconds
at 1,024 rows, and 27.663 versus 3.276 seconds at 8,192 rows.

The packaged 504 formal records predate the `protocol` field. Their reader
scope must be checked against the run records and direct-probe logs; it cannot
be recovered from a nonexistent JSONL field. New runs record `reader_scope`,
protocol schema, and a measurement-source digest. Comment-only source edits
change that digest without changing the measurement algorithm; do not rewrite
historical records to attach the current digest or protocol fields.

Requested grouping arguments do not establish physical equivalence. Parquet
uses rows, ORC uses one measured bytes-per-row conversion per dataset, and the
tested Lance grouping argument emits a singleton layout under a fixed file
cap. The six Lance cells measure one file, so the default-point leader is decided
against their median and optimized comparisons are reported against their full
range, which serves as the tie band. ORC's omitted-argument default falls
between the 524,288- and 1,048,576-row cells, and every ORC default-pairing
value is reported at both neighbors. The unsigned-column widening applies to every writer.

```bash
python scripts/report_grid.py results/p2_qualified_20260821
```

Regenerate the formal table summaries from `artifact/`:

```bash
python scripts/report_rerun.py results/p2_qualified_20260821
python scripts/report_rerun.py results/p2_qualified_20260821 --tex
```

Use separate invocations for separate hosts and protocol generations. The
summary script reads direct JSONL children and prints noise warnings; it is
not a substitute for checkpoint and provenance validation.

`probe_metadata_share.py` fits footer cost by default. Its `--direct` option
reads and decompresses data and must not run alongside timed experiments.
Supply `--direct-file` to choose the layout, `--threads 1` for the paper's
thread setting, and `--window 362039` for the ClickBench-32p shuffle. Omitting
`--columns` uses the paper's ten-column projection when those columns exist;
other schemas fall back to their first ten columns and are not the same workload.

The auxiliary-host `group_overhead_fit.json` and
`two_term_model_validation.json` support the model's earlier calibration and
held-out checks. They do not validate the fitted coefficient on the formal
RAID5 run. Readahead experiments and Windows references have separate evidence
scopes as described in `results/README.md`.

`scripts/probe_orc_default_mapping.py` and `scripts/probe_lance_default_mapping.py`
locate each writer's default point by omitting the argument rather than assuming
it. Omitting ORC's stripe size emits a layout between two swept settings, so its
default-pairing figures are proxies. For Lance, omitting the row-group argument
while retaining the sweep's fixed file-size cap emits exactly the layout all
six requests produce, so any swept cell represents the conditional grouping
default under that policy. It is not the writer's complete library default.
